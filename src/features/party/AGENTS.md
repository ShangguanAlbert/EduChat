# party feature 协作说明

本文件适用于 `src/features/party/` 目录及其子目录。

## 职责范围

- 群聊 / party chat 前端页面入口

## 修改原则

- 保持 feature 层轻量，优先作为路由和页面入口
- 如果涉及实时通信、共享状态或桌面/移动分层，先检查现有 `src/pages/party-chat/` 相关实现，再做增量调整
- 路径命名继续沿用 `/party`
- 施高俊授课范围下的右侧区域是 PAIA HTML/CSS 结对编程区，不是派 Agent；群聊左栏、聊天窗口和群内 `@AI` 保持其独立职责
- 桌面端左栏是可收起的覆盖式信息栏，聊天与编程区支持调整宽度；改布局时不得重新压缩主聊天区，也要保留移动端抽屉行为
- 任务发布栏、任务附件、当前 HTML/CSS 和诊断会作为群聊 AI 的服务端上下文；仅 Driver 编辑和刷新预览，Navigator 参与讨论与检查
